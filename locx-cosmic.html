LOCX Cosmic

A workspace for coding agents.

Your providers, your keys

Single Coder gives one agent a workspace. Team Coder lets several work on the same task. Both keep their memory between runs and report each step in the activity stream.

Codex and Antigravity use the subscription you already have installed. For other models, add an OpenAI-compatible base URL and key under Providers & Teams. The key stays in local app data and is not shown again.

Windows x64 builds ship as a portable executable, an NSIS setup and an MSI. The engine folder sits beside the portable build.
