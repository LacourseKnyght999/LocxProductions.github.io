Workbench notes.

Short notes on direction and craft from the studio workbench.

NOTE 01

Four shelves, one rule

We keep a folder with four shelves: built, checked, for sale, published. A build only moves when the licence, a clean install and the advertised features actually hold up.

NOTE 02

It runs on your machine

Our tools run on your machine. If a service is optional, the interface says so. If an engine isn't installed, it says that too.

NOTE 03

Pulling the drive letters out

We pulled dozens of hardcoded drive paths out of 3D Studio. It should install anywhere without needing a developer's folder layout.
