LOCX 3D Studio

A local, offline 3D asset workshop. Image to geometry, texturing, mesh optimization, rigging helpers, QA and GLB export — in one app that keeps your work on your machine.

Pending approval v1.0.0 Windows 10/11 x64 Ship gate 12/12

What it does

The studio covers the path from a single reference image to a checked, exportable GLB. Work areas include image-to-3D, PBR retexturing of existing meshes, Blender-based optimization that preserves UVs and materials, GLB clip playback, asset versions and structural QA, plus Unreal handoff helpers.

Nothing is uploaded. The app talks only to local loopback services. Model packs are deliberately not bundled — the lightweight payload ships with a setup CLI that discovers packs already on your machine or downloads only the ones you choose, then reports honestly when an engine is unavailable.

Portability was rebuilt from the ground up: 47 hardcoded drive paths were replaced with a resolver that reads configuration, environment variables and portable defaults. The app can be moved or relocated without breaking.

from the workbench

“The rule was simple: nothing leaves the machine, and no engine silently pretends to work. If a route isn't ready, the app says so.”

Workflows

  • Image to 3D — single or primary reference to textured GLB
  • Texture generation — PBR retexturing of an existing mesh
  • Optimize model — decimation with UV/PBR preserved
  • Rig & animate — GLB clip playback; auto-rig is safety-gated
  • Asset library and workshop QA — versions, references, structural checks
  • Export — GLB, plus Unreal handoff helpers

Requirements & payload

Windows 10/11 x64. NVIDIA GPU with CUDA for generation workflows — the viewer and UI work without one. Blender 4.2+ for optimize, bake, repair and environment workflows. Python 3.11–3.13 for a few worker scripts. Disk space for whichever model packs you download.
