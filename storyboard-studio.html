LOCX Storyboard Studio

A standalone local web app and storyboard editor. Plan scenes, build shots, collect references and explore concepts on a freeform canvas, without turning your storyboard into a hosted service.

v1.1.0 Windows · localhost

What it does

Storyboard Studio keeps projects, scenes and shots on your own machine. Each shot carries camera direction, prompts, audio and dialogue notes, and timing. Scenes and shots can be reordered, and projects export and import as JSON.

The reference library holds characters, locations, props and costumes with optional uploaded images. The Concept Mixboard is an integrated, freeform canvas for image, colour and note cards. You can move, resize, zoom, undo and combine visuals, then send a finished image straight into a storyboard shot.

Image generation is optional. Configure an OpenAI key for generate, edit and remix, or point the app at local text-to-image executables. Without a provider, everything else still works and the interface says so.

Note

"We made this because story canon kept drifting between documents, images and shots. One local place for all of it, with no pretend generators when no provider is configured."

LK and AB

Feature set

  • Multiple projects with a seeded four-scene example
  • Scenes, shots, camera notes, prompts, audio/dialogue and timing
  • Scene and shot reordering with local persistence
  • Character, location, prop and costume reference library
  • Concept Mixboard: cards, zoom, pan, undo/redo, PNG export
  • Send a mixboard image to a scene as a linked shot
  • Optional image providers. No fake generated images
  • MCP adapter so an agent can operate scene and shot data
