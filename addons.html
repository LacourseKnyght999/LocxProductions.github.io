AisleSmith

Nine fixture generators in one Blender panel.

Pallet racks, boltless shelving, cantilevers, gondolas, benches, pallets, crates, totes and barriers. Place one, a row or a grid. Set the spacing, bays, levels, palette and seed. The meshes stay editable.

  • Parametric geometry in pure Python
  • Five palettes and three detail levels
  • Runs locally in Blender 4.2 and 5.3 on Windows
  • GPL-3.0-or-later with the Python source included
