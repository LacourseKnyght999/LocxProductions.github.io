# LOCX Industries — website

A self-contained static site for LOCX Industries. No build step, no dependencies, no tracking.

## Run locally

Open `index.html` in a browser, or serve the folder:

```powershell
cd "C:\Users\Lacourse\LOCX Industries"
python -m http.server 8080
```

Then visit `http://localhost:8080`.

## Deploy

Copy the whole folder to any static host (Netlify, Cloudflare Pages, GitHub Pages, S3, or a plain web server). Keep the `assets/` folder next to the HTML files so relative links work.

## Before going live

1. Replace `hello@locxindustries.com` in `index.html`, `aislesmith.html` and `assets/js/main.js` with your real contact address.
2. If AisleSmith clears marketplace review, update its status chip, side panel and callout. Prices are deliberately not shown while products are unverified.
3. If a packaged product clears approval, move it to the "Approved for Sale" tier in `G:\LOCX Products` first, then update its status chip, side panel and callout here.
4. Wire the early-access form to a real endpoint. Set `data-lead-endpoint` on `<body>` to your form handler URL (JSON POST). Until then, submitting prepares a prefilled email to your contact address and shows a manual-send fallback — no submission is silently swallowed. The form also carries Netlify attributes, so it works as-is if you deploy to Netlify.
5. Add analytics only if you want them. The site deliberately has no countdowns, fake scarcity, preselected consent, or hidden pricing: products are unverified, so the conversion path is "request early access", not "buy now".

## Copy pass

Public prose was rewritten with the Humanizer v4.0.0 rules (`blader/humanizer`): no em dashes, no staged openers, no "not X but Y" padding, no forced triads, no decorative bold or arrows, no chatbot residue. The site presents products with version and build labels only. It carries no pending/coming-soon/early-access language and makes no sale or release claims.

## Design rules in use

Applied the taste-skill rules for a software site: real product UI in the hero, no captions or labels under images, one type-led moment, equal content edges, hero entrance and hover/press motion, and a single button and card system. Copy follows Humanizer v4.0.0.

## Visual system

Blue / silver / grey / white. Clean editorial layout, rounded panels, generous space, real product screenshots in the hero. No instrument-panel framing, rulers, brackets or neon glow. Headings use Windows' Bahnschrift with Segoe UI fallbacks; body uses Segoe UI; small labels use a monospace stack.
